# P09 — AI Controllo di Gestione
## Servizio K2-AI
Agenti AI per il controllo di gestione: dashboard KPI, analisi scostamenti, budget, pricing, analisi di bilancio e reporting direzionale.

## Skill Claude disponibili

| Skill | Descrizione |
|-------|-------------|
| `finance:financial-statements` | P&L, stato patrimoniale, cash flow con analisi scostamenti periodo |
| `finance:variance-analysis` | Analisi varianze budget vs actual con waterfall e narrative |
| `finance:close-management` | Chiusura mensile: task, dipendenze, calendario, tracking avanzamento |
| `finance:reconciliation` | Riconciliazione GL, estratto conto, subledger, intercompany |
| `controllo-gestione-bocconi` | ABC, budget flessibili, scostamenti avanzati, BSC, EVA, transfer pricing |
| `programmazione-controllo` | CVR, BEP, margine di contribuzione, leva operativa, budget, job costing |
| `analisi-bilancio-pmi` | Riclassificazione SP/CE, 25+ indici, trend 3 anni, benchmark settore |
| `cruscotto-direzionale` | Dashboard KPI mensile con 4 prospettive BSC, semafori, alert anomalie |
| `budget-forecast-pmi` | Budget previsionale 12 mesi con scenari e sensitivity analysis |
| `pricing-optimizer` | Analisi margini, BEP per prodotto, simulazione pricing what-if |
| `data:analyze` | Analisi dati da semplice lookup a report completo con trend e driver |
| `data:build-dashboard` | Dashboard HTML interattiva con KPI card, filtri, grafici |
| `data:statistical-analysis` | Statistiche descrittive, test ipotesi, outlier detection, correlazioni |
| `data:create-viz` | Visualizzazioni dati con Python (matplotlib, seaborn, plotly) |

## Come usarle
Es: "crea il cruscotto KPI di aprile" → `cruscotto-direzionale`
Es: "analizza gli scostamenti budget di questo trimestre" → `finance:variance-analysis`
Es: "qual è il margine di contribuzione per prodotto?" → `programmazione-controllo`

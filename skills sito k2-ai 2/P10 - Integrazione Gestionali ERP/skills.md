# P10 — Integrazione Gestionali ERP
## Servizio K2-AI
Progettazione e supporto all'integrazione tra sistemi gestionali, ERP, database e applicazioni aziendali tramite API e architetture modulari.

## Skill Claude disponibili

| Skill | Descrizione |
|-------|-------------|
| `engineering:architecture` | ADR: scelte architetturali con trade-off, conseguenze e alternative |
| `engineering:system-design` | Progetta sistemi, servizi, API e confini tra microservizi |
| `engineering:debug` | Sessione di debug strutturata: riproduce, isola, diagnostica e corregge |
| `engineering:deploy-checklist` | Checklist pre-deploy: migrazioni, feature flag, CI, rollback trigger |
| `engineering:testing-strategy` | Strategia di test: piani, copertura, architettura test |
| `engineering:code-review` | Code review: sicurezza, performance, correttezza, N+1 query |
| `operations:change-request` | Change request con impact analysis e rollback plan per CAB review |
| `operations:risk-assessment` | Identifica, valuta e mitiga rischi operativi su progetto/vendor/processo |
| `operations:vendor-review` | Valuta vendor: TCO, risk assessment, raccomandazione, punti negoziazione |
| `data:sql-queries` | SQL ottimizzato per tutti i principali data warehouse (Snowflake, BigQuery…) |
| `data:write-query` | Traduce bisogni in linguaggio naturale in SQL con CTE e window function |
| `data:explore-data` | Profila dataset: shape, qualità, distribuzione, duplicati, anomalie |

## Come usarle
Es: "come integro il gestionale con il CRM via API REST?" → `engineering:system-design`
Es: "scrivi la query per estrarre gli ordini del mese da SAP" → `data:sql-queries`
Es: "prepara la change request per il rilascio del modulo magazzino" → `operations:change-request`

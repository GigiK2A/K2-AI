# P02 — Automazioni Amministrative
## Servizio K2-AI
Automazione di processi amministrativi, contabili e documentali: fatture, registrazioni contabili, rendiconti, modelli office.

## Skill Claude disponibili

| Skill | Descrizione |
|-------|-------------|
| `xlsx` | Crea, modifica e analizza file Excel (.xlsx) con formule, grafici e pivot |
| `docx` | Crea e modifica documenti Word (.docx) professionali con formattazione avanzata |
| `pdf` | Gestione PDF: estrazione testo, creazione, merge, split, compilazione form |
| `pptx` | Crea e modifica presentazioni PowerPoint (.pptx) |
| `finance:journal-entry` | Prepara scritture contabili con dare/avere e documentazione di supporto |
| `finance:journal-entry-prep` | Scritture di chiusura: ratei, risconti, ammortamenti, accantonamenti |
| `finance:reconciliation` | Riconciliazione conti: GL vs estratto conto, subledger, intercompany |
| `finance:close-management` | Gestione chiusura mensile: sequenza task, dipendenze, stato avanzamento |
| `finance:financial-statements` | Genera P&L, stato patrimoniale, cash flow con analisi scostamenti |
| `finance:variance-analysis` | Analisi varianze budget vs actual con waterfall e narrative |
| `operations:process-doc` | Documenta processi aziendali con flowchart, RACI, SOP |
| `contabilita-bilancio` | Contabilità generale italiana, bilanci OIC/IFRS, partita doppia, IVA |

## Come usarle
Es: "crea un foglio Excel per la riconciliazione bancaria di aprile" → `xlsx`
Es: "scrivi le scritture di chiusura per il mese" → `finance:journal-entry-prep`

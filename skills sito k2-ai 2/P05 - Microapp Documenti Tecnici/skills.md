# P05 — Microapp Documenti Tecnici
## Servizio K2-AI
Generazione automatica di documenti tecnici, report, manuali, runbook e presentazioni da template o da input strutturato.

## Skill Claude disponibili

| Skill | Descrizione |
|-------|-------------|
| `docx` | Crea documenti Word professionali con TOC, intestazioni, tabelle, stili |
| `xlsx` | Genera fogli Excel con formule vive, pivot, grafici e formattazione condizionale |
| `pdf` | Crea, compila e manipola PDF; estrazione tabelle e testo |
| `pptx` | Costruisce presentazioni PowerPoint con layout e design |
| `engineering:documentation` | Documentazione tecnica: README, API docs, runbook, guide onboarding |
| `operations:runbook` | Runbook operativi con step esatti, troubleshooting e escalation path |
| `operations:process-doc` | Documenta processi: flowchart, RACI, SOP, edge case |
| `prompt-engineer-tecnico` | Crea prompt enterprise multi-step per task tecnici su Claude/Claude Code |
| `engineering:system-design` | Documenta architetture di sistema, servizi, API, modelli dati |
| `engineering:architecture` | Architecture Decision Record (ADR): scelte tecnologiche con trade-off |

## Come usarle
Es: "crea un manuale d'uso in Word per questo sistema" → `docx`
Es: "genera un runbook per il deploy in produzione" → `operations:runbook`
Es: "fai una presentazione tecnica in 10 slide" → `pptx`

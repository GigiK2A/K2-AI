# P08 — AI Compliance e Audit
## Servizio K2-AI
Agenti AI per compliance normativa, audit interni, SOX, sicurezza sul lavoro, agevolazioni fiscali e verifiche regolatorie.

## Skill Claude disponibili

| Skill | Descrizione |
|-------|-------------|
| `finance:audit-support` | SOX 404: test di controllo, selezione campioni, workpaper, deficienze |
| `finance:sox-testing` | Piano test SOX trimestrale/annuale, campioni, workpaper, classificazione NC |
| `legal:compliance-check` | Verifica conformità di azioni o iniziative alle normative applicabili |
| `operations:compliance-tracking` | Traccia requisiti compliance e readiness per audit (SOC 2, ISO 27001, GDPR) |
| `consulente-sicurezza-lavoro` | D.Lgs. 81/2008: DVR, RSPP, formazione, sorveglianza sanitaria, DPI |
| `it-law-privacy-ai` | GDPR, AI Act, NIS2, Data Act: compliance normativa digitale |
| `antitrust-concorrenza-ue` | Art. 101/102 TFEU, merger control, compliance antitrust |
| `fiscale-tributario-italiano` | Accertamenti fiscali, ravvedimento, tax credit, compliance tributaria |
| `verifica-requisiti-transizione5` | Ammissibilità Transizione 5.0 / 4.0: aliquote, documentazione, GSE |
| `rendicontazione-agevolazioni` | Rendicontazione e chiusura pratiche finanza agevolata post-concessione |
| `calcolo-de-minimis` | Calcolo de minimis residuo (soglia 300k EUR, Reg. UE 2023/2831) |

## Come usarle
Es: "verifica se questo investimento è ammissibile a Transizione 5.0" → `verifica-requisiti-transizione5`
Es: "prepara i workpaper per il test SOX del controllo vendite" → `finance:sox-testing`
Es: "dobbiamo fare il DVR? cosa serve?" → `consulente-sicurezza-lavoro`

1. Identifica il piano: organizzativo, governance, leadership, CSR/stakeholder, o processi.
2. Leggi la reference pertinente prima di rispondere.
3. Cita modelli canonici (Mintzberg, Williamson TCE, Freeman, Kotter 8-step, Schein).
4. Per strategia competitiva richiama `strategia-competitiva` o `strategia-grant-bocconi`.
5. Per controllo di gestione richiama `programmazione-controllo` o `controllo-gestione-bocconi`.

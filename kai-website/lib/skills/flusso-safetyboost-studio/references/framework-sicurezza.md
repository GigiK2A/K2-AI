# Framework Sicurezza Cantiere — D.Lgs. 81/2008

## Obblighi per soglia

| Condizione | PSC | CSP | CSE | Notifica |
|-----------|-----|-----|-----|----------|
| 1 impresa, < 200 u-g | No | No | No | No |
| 1 impresa, >= 200 u-g | No | No | No | Si |
| 2+ imprese (anche non contemp.) | Si | Si | Si | Si se > 200 u-g |
| Rischi particolari All. XI | Si | Si | Si | Si |

## Struttura PSC (Allegato XV)

1. Identificazione e descrizione dell'opera
2. Individuazione soggetti con compiti di sicurezza
3. Relazione rischi particolari (All. XI): caduta > 2m, sprofondamento, seppellimento, annegamento, elettrocuzione, esplosivi, agenti chimici/biologici, radiazioni ionizzanti, linee elettriche, rischio incendio/esplosione
4. Scelte progettuali e organizzative
5. Prescrizioni operative per fasi critiche con interferenze
6. Misure di coordinamento uso comune mezzi e servizi
7. Organizzazione prevista per servizi sanitari e pronto soccorso
8. Procedure di emergenza
9. Durata prevista fasi critiche
10. Stima costi sicurezza

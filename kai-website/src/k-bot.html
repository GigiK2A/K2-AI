Come funziona
01

Descrivi il caso

Scrivi in linguaggio naturale: tipo di struttura, problema, obiettivo. K-BOT capisce il contesto e attiva le skill verticali corrette tra le 49 disponibili — senza menù, senza form.

02

K-BOT raccoglie i dati

Se mancano informazioni chiave, K-BOT fa una domanda alla volta seguendo il workflow della skill. Se i dati numerici non ci sono, usa benchmark di mercato aggiornati via web — e lo indica esplicitamente nel report.

03

Genera il documento

Il motore Claude produce un HTML completo con design system K2-AI: executive summary, KPI con semafori, gap analysis in €/anno, azioni con step operativi, timing e KPI di misura. Poi lo converte in PDF via browser headless.

04

Scarica e usa

Apri il report HTML nel browser o scarica il PDF. Puoi continuare la chat per approfondire sezioni, chiedere varianti o usare il report come base per la call col cliente.

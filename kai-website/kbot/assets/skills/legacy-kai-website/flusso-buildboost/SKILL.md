# BuildBoost — Orchestratore Studi Professionali Edilizia

## Quando attivare BuildBoost

Usa questo flusso quando lo studio gestisce:
- Progettazione e direzione lavori su commesse edili/strutturali/impiantistiche
- Partecipazione a gare d'appalto pubbliche (D.Lgs. 36/2023)
- Redazione capitolati speciali e computi metrici
- Gestione avanzamento lavori (SAL) e contabilità cantiere
- Pratiche SCIA/DIA/PCIA/permesso di costruire

## Step 1 — Diagnosi commessa

Raccogliere:
- Tipo commessa: pubblica (gara) / privata (incarico diretto) / misto
- Settore: civile residenziale / industriale / infrastrutture / restauro / TLC
- Importo lavori stimato
- Fase attuale: progettazione preliminare / definitiva / esecutiva / DL
- Risorse studio: n. progettisti, n. cantieri attivi

## Step 2 — Iter appalto pubblico (D.Lgs. 36/2023)

```
FASI PROCEDURA APERTA (> 5,35M€ lavori)
────────────────────────────────────────
1. Bando/Avviso GURI + portale e-procurement
2. Sopralluogo obbligatorio (se previsto)
3. Offerta tecnica + economica entro scadenza
4. Apertura plichi, verifica requisiti
5. Valutazione OEPV (offerta economicamente più vantaggiosa)
6. Proposta aggiudicazione → verifica anti-mafia → aggiudicazione definitiva
7. Stipula contratto → consegna lavori → esecuzione
```

Per **servizi di architettura/ingegneria** (> 215k€): procedura negoziata previa pubblicazione o aperta con criteri OEPV.

## Step 3 — Documentazione tecnica gara

| Documento | Chi redige | Note |
|-----------|------------|------|
| Relazione tecnica illustrativa | Studio | Max 30 pagine + allegati |
| Elaborati grafici | Studio | Scala e formato da bando |
| Computo metrico estimativo | Studio | Prezziario regionale |
| Cronoprogramma | Studio | Gantt con fasi e milestone |
| Piano qualità | Studio | ISO 9001 se richiesto |
| Curriculum vitarum | Studio/Professionisti | Esperienza specifica richiesta |
| Referenze | Studio | Certificati di buona esecuzione |

## Step 4 — Parcella professionale

Riferimento: D.M. 17/06/2016 (ex D.M. 140/2012) per liquidazione giudiziale.
In pratica: accordo libero tra le parti, ma benchmark utile.

**Parametri base**:
```
Parcella = Qb × G × P
Qb = valore opera (parametro base per categoria)
G  = grado di complessità (0.85 — 1.30)
P  = prestazione (% sul Qb per fase progettuale)

Fasi tipiche:
- Progettazione preliminare: 15%
- Progettazione definitiva: 25%
- Progettazione esecutiva: 30%
- Direzione Lavori: 25%
- CSE (coordinamento sicurezza esecuzione): 5%
```

## Step 5 — Contabilità lavori e SAL

Registro di contabilità: documenta ogni lavorazione con:
- Data misurazione
- Descrizione voce di capitolato
- Unità di misura + quantità
- Prezzo unitario + importo parziale

**SAL (Stato Avanzamento Lavori)**:
- Frequenza: mensile o al raggiungimento della soglia contrattuale
- Contenuto: importo lavori eseguiti, materiali in cantiere, ritenute, IVA
- Firma: DL + Impresa → Committente emette Certificato di Pagamento

## Regole operative BuildBoost

- Ogni commessa ha un fascicolo digitale con: contratto, progetto esecutivo, SAL, corrispondenza
- DVR e POS obbligatori prima di consegnare cantiere
- Varianti > 5% importo contrattuale: iter autorizzativo committente
- Riserve appaltatore: forma scritta, entro 15gg dalla registrazione contabilità (art. 121 D.Lgs. 36/2023)
- Polizza RC professionale: citarla sempre in contratto di incarico

## Output tipici BuildBoost

- Piano commessa con milestone e responsabilità
- Checklist documentazione gara completa
- Modello SAL mensile compilabile
- Template parcella professionale con campi calcolati
- Report avanzamento cantieri attivi

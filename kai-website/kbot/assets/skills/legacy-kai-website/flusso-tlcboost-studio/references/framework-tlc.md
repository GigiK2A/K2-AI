# Framework Project Management Siti TLC — Italia

## Ciclo di vita sito TLC

```
Ordine → TSSR → PE → Autorizzazione → Cantiere → Commissioning → BEF
```

## Fasi e tempi tipici

| Fase | Durata tipica | Controllabile? | Dipendenze |
|------|-------------|---------------|-----------|
| TSSR / Sopralluogo | 1-2 settimane | Si | Accesso al sito |
| Progettazione Esecutiva (PE) | 2-4 settimane | Si | TSSR completato |
| Iter autorizzativo (SCIA art. 45) | 30 giorni (silenzio-assenso) | Parziale | PE completato |
| Autorizzazione paesaggistica | 45-90 giorni | No | PE + relazione paesaggistica |
| Parere Soprintendenza | 60-120 giorni | No | Relazione monumentale |
| Nulla osta ENAC | 30-60 giorni | No | Coordinate e altezze |
| Cantiere - opere civili | 1-3 settimane | Si | Autorizzazione ottenuta |
| Cantiere - montaggio struttura | 1-2 settimane | Si | Opere civili completate |
| Cantiere - installazione apparati | 1-2 settimane | Si | Struttura completata |
| Cantiere - impianto elettrico | 1 settimana | Si | Apparati installati |
| Commissioning | 2-5 giorni | Parziale | Impianti completati |
| Certificazioni e BEF | 1-2 settimane | Si | Commissioning OK |

## Iter autorizzativo per tipo

### SCIA art. 45 D.Lgs. 259/2003 (caso standard)
- Deposito al SUAP/Comune
- 30 giorni silenzio-assenso (90 gg con vincoli)
- Allegati obbligatori: relazione tecnica, planimetria, sezioni, prospetti, scheda radio, asseverazione RF, asseverazione urbanistica, asseverazione edilizia, titolo disponibilita area

### Con vincolo paesaggistico
- Autorizzazione paesaggistica semplificata (DPR 31/2017 voce A.25): 45 gg
- Autorizzazione paesaggistica ordinaria: 90 gg
- Relazione paesaggistica + fotosimulazione

### Con vincolo monumentale
- Parere Soprintendenza: 60-120 gg
- Relazione compatibilita + elaborati dettagliati

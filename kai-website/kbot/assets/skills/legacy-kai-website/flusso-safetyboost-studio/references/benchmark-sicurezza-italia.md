# Benchmark Costi Sicurezza — Italia 2024-2025

## Incidenza costi sicurezza su importo lavori

| Tipologia cantiere | Incidenza % | Note |
|-------------------|------------|------|
| Ristrutturazione edilizia | 3-5% | Rischi standard |
| Nuova costruzione residenziale | 3-4% | Rischi medio-bassi |
| Nuova costruzione industriale | 4-6% | Altezze, sollevamenti |
| Infrastrutture stradali | 5-8% | Traffico, scavi profondi |
| Cantiere TLC rawland | 4-6% | Lavori in quota, sollevamento palo |
| Cantiere TLC rooftop | 5-8% | Lavori in quota, RF, accesso |
| Bonifica amianto | 8-15% | Rischio specifico alto |
| Lavori in sotterraneo | 10-15% | Spazi confinati, ventilazione |

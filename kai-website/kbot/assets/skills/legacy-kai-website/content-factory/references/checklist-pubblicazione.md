# Checklist pubblicazione articolo

## Ogni articolo prima di andare live deve passare questi controlli

Dividere la checklist in: **on-page SEO**, **UX/accessibility**, **tracking/tecnica**, **promozione**.

---

## On-page SEO

- [ ] **H1 unico** nella pagina, contiene keyword primaria, ≤ 70 caratteri
- [ ] **Meta title** ≤ 60 caratteri, keyword primaria entro primi 40 caratteri, brand alla fine
- [ ] **Meta description** 130-155 caratteri, contiene keyword + CTA implicita
- [ ] **URL slug** short (≤ 60 caratteri), keyword primaria, trattini, no numeri casuali
- [ ] **Canonical URL** auto o manuale (se ci sono versioni alternative)
- [ ] **Open Graph tag** (og:title, og:description, og:image) compilati
- [ ] **Twitter Card** (summary_large_image)
- [ ] **Schema markup** Article (minimo), FAQ se c'è sezione FAQ, HowTo se l'articolo è procedurale
- [ ] **Keyword primaria** presente in: H1, primo paragrafo, almeno 2 H2, conclusione
- [ ] **Densità keyword** primaria 1-2% (non più, non meno)
- [ ] **Keyword secondarie** distribuite nel testo, in H2/H3 dove naturale
- [ ] **Internal link** minimo 2, massimo 5, con anchor text naturale
- [ ] **External link** a fonti autorevoli (1-2, opzionali, rel="noopener")
- [ ] **Immagini** con alt text descrittivo e keyword quando pertinente
- [ ] **Nomi file immagini** in kebab-case con keyword (es. `caldaia-condensazione-installazione.webp`)

## UX / Accessibilità

- [ ] **Paragrafi brevi** (3-5 righe, leggibili su mobile)
- [ ] **Sottolineato usato solo per link** (mai per enfasi)
- [ ] **Grassetto** usato su concetti chiave, non su intere frasi
- [ ] **Liste puntate/numerate** quando il contenuto si presta
- [ ] **TOC (indice)** se articolo > 1.500 parole
- [ ] **Immagini compresse** (WebP, max 200KB ciascuna)
- [ ] **Responsive check** visualizzazione su mobile (iPhone standard)
- [ ] **Contrasto testo/sfondo** ≥ AA WCAG
- [ ] **Scrolling depth** fluido (no elementi che interrompono la lettura)
- [ ] **CTA visibile sopra la piega mobile** (primo screen)
- [ ] **CTA finale** prominente con bottone

## Tracking e tecnica

- [ ] **Google Analytics** traccia la pagina (verifica real-time)
- [ ] **Google Search Console** proprietà configurata, sitemap aggiornata
- [ ] **URL indicizzabile** (no noindex per errore)
- [ ] **Robots.txt** non blocca
- [ ] **Sitemap.xml** include il nuovo URL
- [ ] **UTM parameters** sui link CTA (per misurare conversioni)
- [ ] **Event tracking** sui click CTA (GA4 o altro)
- [ ] **Tempo di caricamento** ≤ 3s (PageSpeed Insights)
- [ ] **Core Web Vitals** verde (LCP ≤ 2.5s, CLS ≤ 0.1, INP ≤ 200ms)
- [ ] **SSL** attivo (HTTPS)
- [ ] **Mobile-friendly test** (Google) passato
- [ ] **Richiesta indicizzazione** via Search Console (URL inspection tool)

## Promozione (post-pubblicazione)

- [ ] **Condivisione social** (LinkedIn, Facebook, Instagram a seconda del target)
- [ ] **Newsletter** se il cliente ha lista e-mail (segmentata per interesse)
- [ ] **Google Business Profile post** se articolo è locale/commerciale
- [ ] **Link interno da altre pagine pertinenti** (aggiungere link in 1-2 articoli vecchi che parlano di temi correlati)
- [ ] **Outreach** (se l'articolo cita enti o persone: notifica via email)
- [ ] **Ripubblicazione pezzo su Medium / LinkedIn Article** dopo 2 settimane (se piano Intensive)

## Quality gate finale

Prima di marcare come pubblicato:
- [ ] Il cliente ha approvato il testo
- [ ] Non ci sono errori di battitura (doppio check)
- [ ] I link funzionano (manual test)
- [ ] Le immagini caricano
- [ ] La CTA è cliccabile e porta alla pagina giusta
- [ ] La preview Google (meta title + description) è accattivante
- [ ] La preview social (og:image) è corretta

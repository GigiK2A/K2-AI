# Guida alla Riclassificazione del Bilancio per PMI Italiane

Come passare dallo schema civilistico (artt. 2424-2425 c.c.) agli schemi riclassificati per l'analisi.

---

## 1. Riclassificazione dello Stato Patrimoniale

### 1.1 Criterio Liquidita / Esigibilita

L'attivo viene ordinato per grado di liquidita (velocita di conversione in cassa), il passivo per grado di esigibilita (scadenza temporale).

#### ATTIVO

| Voce riclassificata | Voci civilistiche (art. 2424) | Note |
|---|---|---|
| **ATTIVO FISSO (Immobilizzato)** | | |
| Immobilizzazioni immateriali | B.I (1-7) | Al netto dei fondi ammortamento |
| Immobilizzazioni materiali | B.II (1-5) | Al netto dei fondi ammortamento |
| Immobilizzazioni finanziarie | B.III (1-4) | Partecipazioni, crediti M/L, titoli, azioni proprie |
| Crediti oltre 12 mesi | Quota oltre 12 mesi di C.II | Riclassificare nell'attivo fisso |
| **ATTIVO CORRENTE (Circolante)** | | |
| Rimanenze | C.I (1-5) | Materie prime, semilavorati, lavori in corso, prodotti finiti, acconti |
| Crediti commerciali a breve | C.II.1 (quota entro 12 mesi) | Crediti verso clienti |
| Altri crediti a breve | C.II (2-5) quota entro 12 mesi | Crediti tributari, imposte anticipate, verso altri |
| Attivita finanziarie a breve | C.III (1-7) | Partecipazioni e titoli che non costituiscono immobilizzazioni |
| Disponibilita liquide | C.IV (1-3) | Depositi bancari, assegni, cassa |
| Ratei e risconti attivi | D | Solo quota a breve (entro 12 mesi) |

#### PASSIVO

| Voce riclassificata | Voci civilistiche (art. 2424) | Note |
|---|---|---|
| **PATRIMONIO NETTO** | A (I-IX) | Capitale, riserve, utili/perdite portati a nuovo, utile esercizio |
| **PASSIVO CONSOLIDATO (M/L termine)** | | |
| Fondi per rischi e oneri | B (1-4) | Se a scadenza oltre 12 mesi |
| TFR | C | Intero importo (debito a lungo per natura) |
| Debiti finanziari M/L | D (1+3+4) quota oltre 12 mesi | Obbligazioni, debiti vs banche, altri finanziatori |
| Altri debiti M/L | D (restanti) quota oltre 12 mesi | |
| Ratei e risconti passivi M/L | E | Quota oltre 12 mesi |
| **PASSIVO CORRENTE (a breve)** | | |
| Debiti finanziari a breve | D (1+3+4) quota entro 12 mesi | Obbligazioni, banche, finanziatori entro 12 mesi |
| Debiti commerciali | D.7 | Debiti verso fornitori |
| Altri debiti a breve | D (restanti) quota entro 12 mesi | Tributari, previdenziali, altri debiti |
| Ratei e risconti passivi a breve | E | Quota entro 12 mesi |

**Punto chiave**: l'art. 2424 c.c. richiede gia la distinzione entro/oltre 12 mesi per crediti e debiti. Se il bilancio non la esplicita, chiedere all'utente o stimare in base alla natura della voce.

### 1.2 Criterio Funzionale

Separa il capitale investito nell'attivita operativa (core business) da quello accessorio.

| Voce riclassificata | Contenuto |
|---|---|
| **CAPITALE INVESTITO OPERATIVO** | |
| Attivo fisso operativo | Immobilizzazioni materiali e immateriali legate al core business |
| CCN operativo | Crediti commerciali + Rimanenze - Debiti commerciali - Ratei/risconti operativi |
| Fondi operativi (da sottrarre) | TFR, fondi rischi operativi |
| **CAPITALE ACCESSORIO** | |
| Immobilizzazioni finanziarie | Partecipazioni non strategiche, titoli |
| Attivita finanziarie a breve | Titoli, depositi vincolati |
| Immobili non strumentali | Immobili non utilizzati nell'attivita |
| **FONTI DI FINANZIAMENTO** | |
| Patrimonio Netto | A (I-IX) |
| Posizione Finanziaria Netta (PFN) | Debiti finanziari - Disponibilita liquide - Attivita finanziarie a breve |

**PFN (Posizione Finanziaria Netta)**: debiti finanziari totali (obbligazioni + debiti vs banche + debiti vs altri finanziatori) meno disponibilita liquide e attivita finanziarie a breve. E l'indicatore chiave di indebitamento finanziario effettivo.

## 2. Riclassificazione del Conto Economico

### 2.1 Schema a Valore Aggiunto

Riclassifica il CE civilistico (art. 2425 c.c.) per evidenziare i margini intermedi.

| Voce riclassificata | Voci civilistiche | Formula |
|---|---|---|
| **Ricavi netti** | A.1 | Ricavi delle vendite e delle prestazioni |
| + Variazione rimanenze PF/SL | A.2 + A.3 | Variazione rimanenze + Lavori in corso su ordinazione |
| + Incrementi immobilizzazioni | A.4 | Incrementi per lavori interni |
| + Altri ricavi | A.5 | Altri ricavi e proventi |
| = **VALORE DELLA PRODUZIONE** | Totale A | |
| - Costi per materie prime | B.6 | Materie prime, sussidiarie, merci |
| - Costi per servizi | B.7 | Servizi esterni |
| - Costi per godimento beni terzi | B.8 | Affitti, leasing, royalties |
| - Variazione rimanenze MP | B.11 | Variazione rimanenze materie prime |
| - Oneri diversi di gestione | B.14 | |
| = **VALORE AGGIUNTO (VA)** | | VP - Costi esterni |
| - Costi per il personale | B.9 (a+b+c+d+e) | Salari, oneri sociali, TFR, altri costi |
| = **MOL / EBITDA** | | VA - Costo del personale |
| - Ammortamenti immateriali | B.10.a | |
| - Ammortamenti materiali | B.10.b | |
| - Svalutazioni immobilizzazioni | B.10.c | |
| - Svalutazione crediti | B.10.d | |
| - Accantonamenti rischi | B.12 | |
| - Altri accantonamenti | B.13 | |
| = **EBIT (Risultato Operativo)** | | MOL - Ammortamenti - Accantonamenti |

| + Utili/perdite su cambi | C.17-bis | |

**Nota**: le voci straordinarie sono state eliminate dal D.Lgs. 139/2015 e confluiscono in A.5 e B.14.

### 2.2 Schema a Margini (Costo del Venduto)

Utile quando si dispone del dettaglio costi fissi/variabili o della suddivisione per funzione.

| Voce | Composizione |
|---|---|
| **Ricavi netti** | A.1 CE |
| - Costo del venduto (COGS) | Materie prime consumate + Costo lavoro diretto + Ammortamenti industriali + Costi industriali indiretti |
| = **MARGINE LORDO INDUSTRIALE** | |
| - Costi commerciali | Provvigioni, pubblicita, trasporti vendita, personale commerciale |
| - Costi amministrativi | Personale amministrativo, consulenze, spese generali |
| - Costi R&D | Personale R&D, materiali ricerca |
| = **EBIT** | |
| +/- Gestione finanziaria | C.15+C.16-C.17+C.17-bis |
| +/- Rettifiche finanziarie | D (18+19) |
| - Imposte | 20 |
| = **UTILE NETTO** | 21 |

**Attenzione**: il bilancio civilistico italiano classifica i costi per natura (non per funzione/destinazione), quindi per lo schema a margini serve un'elaborazione aggiuntiva o informazioni dal controllo di gestione.

## 4. Rendiconto Finanziario — Metodo Indiretto

Come costruirlo partendo da 2 Stati Patrimoniali consecutivi + Conto Economico.

### Schema (OIC 10)

#### A) Flusso di cassa della gestione operativa (metodo indiretto)

```
Utile (Perdita) dell'esercizio
+ Ammortamenti (B.10.a + B.10.b)
+ Accantonamenti a fondi (B.12 + B.13)
+ Svalutazioni / - Rivalutazioni (B.10.c + B.10.d + D.18 + D.19)
+/- Minusvalenze / Plusvalenze da cessione immobilizzazioni
= AUTOFINANZIAMENTO LORDO (Flusso della gestione reddituale)

+/- Variazione CCN operativo:
  - (Aumento) / Diminuzione crediti commerciali
  - (Aumento) / Diminuzione rimanenze
  - Aumento / (Diminuzione) debiti commerciali
  - (Aumento) / Diminuzione ratei e risconti attivi operativi
  - Aumento / (Diminuzione) ratei e risconti passivi operativi
  - Aumento / (Diminuzione) debiti tributari e previdenziali
+/- Variazione fondi:
  - Utilizzo fondi rischi e oneri
  - Pagamento TFR
+/- Imposte pagate (variazione debiti/crediti tributari)
= FLUSSO DI CASSA OPERATIVO (A)
```

#### B) Flusso di cassa dell'attivita di investimento

```
- Investimenti in immobilizzazioni materiali
- Investimenti in immobilizzazioni immateriali
- Investimenti in immobilizzazioni finanziarie
+ Disinvestimenti (prezzo di cessione)
= FLUSSO DI CASSA DA INVESTIMENTI (B)
```

**Calcolo investimenti**: Immobilizzazioni nette fine anno - Immobilizzazioni nette inizio anno + Ammortamenti dell'anno + Valore netto contabile dei cespiti ceduti

#### C) Flusso di cassa dell'attivita di finanziamento

```
+ Accensione nuovi debiti finanziari
- Rimborso debiti finanziari
+ Aumenti di capitale (versamenti soci)
- Dividendi pagati
+/- Variazione altre voci finanziarie
= FLUSSO DI CASSA DA FINANZIAMENTI (C)
```

#### Verifica quadratura

```
Variazione disponibilita liquide = A + B + C
= Disponibilita liquide fine periodo - Disponibilita liquide inizio periodo
```

### Procedura operativa step-by-step

1. Prendere i due SP (anno N e anno N-1) e il CE dell'anno N
2. Calcolare la variazione di ogni voce di SP (N - N-1)
3. Classificare ogni variazione come operativa, di investimento o di finanziamento
4. Partire dall'utile netto e aggiungere le componenti non monetarie (ammortamenti, accantonamenti)
5. Aggiungere le variazioni di CCN operativo (attenzione al segno: aumento di un attivo = uso di cassa, quindi segno negativo)
6. Calcolare separatamente investimenti e finanziamenti
7. Verificare che A + B + C = variazione disponibilita liquide

# Controllo di Gestione Bocconi

Management accounting avanzato: ABC, budget flessibili, analisi scostamenti, BSC, centri di responsabilita, ROI/EVA, transfer pricing.

## Routing

Leggi `references/controllo-gestione-avanzato.md` per qualsiasi domanda su questi temi con richiesta di formule precise o esempi numerici.

## Istruzioni

1. Per domande base su CVR/BEP/MC → richiama `programmazione-controllo`.
2. Per analisi variance, ABC multi-pool, BSC strutturata, EVA → questa skill.
3. Cita formule esatte con notazione numeratore/denominatore.
4. Usa esempi numerici in euro quando rispondi a quesiti pratici.

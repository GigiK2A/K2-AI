# P18 — AI Design & UX
## Servizio K2-AI
Agenti AI per design di prodotto: critique, design system, handoff sviluppatori, accessibilità, UX copy e ricerca utenti.

## Skill Claude disponibili

| Skill | Descrizione |
|-------|-------------|
| `design:design-critique` | Feedback strutturato su usabilità, gerarchia visiva e consistenza |
| `design:design-system` | Audit, documentazione ed estensione del design system aziendale |
| `design:design-handoff` | Spec handoff per sviluppatori: layout, token, props, stati, animazioni |
| `design:accessibility-review` | Audit WCAG 2.1 AA: contrasto, navigazione tastiera, screen reader |
| `design:ux-copy` | Scrive e revisiona UX copy: microcopy, errori, empty state, CTA |
| `design:user-research` | Pianifica e sintetizza ricerca utenti: interviste, usability test, survey |
| `design:research-synthesis` | Sintetizza ricerca qualitativa in temi, insight e raccomandazioni |
| `anthropic-skills:ux-copy-review` | Revisione UX e copy homepage/landing con annotazioni prima/dopo |

## Come usarle
Es: "fai una critique di questa schermata" → `design:design-critique`
Es: "prepara le spec handoff per gli sviluppatori" → `design:design-handoff`
Es: "questo design è accessibile?" → `design:accessibility-review`

| # | Directory | URL pattern | Priorita | Note |
|---|-----------|-------------|----------|------|
| 1 | Google Business Profile | google.com/maps | Critica | Verifica obbligatoria, base di tutto |
| 2 | Bing Places | bingplaces.com | Alta | Secondo motore, alimenta Copilot |
| 3 | PagineGialle.it | paginegialle.it | Alta | Storica, ancora autorevole in Italia |
| 4 | Misterimprese.it | misterimprese.it | Media | Ampia copertura PMI |
| 5 | Cylex Italia | cylex.it | Media | Citation building |
| 6 | Tuugo Italia | tuugo.it | Media | Citation building |

## Settoriali aggiuntive (per verticale)

- **Ristorazione**: TheFork, TripAdvisor, Quandoo, MyTable
- **Ricettivo**: Booking, Expedia, TripAdvisor, Airbnb
- **Salute**: Dottori.it, MioDottore, Doveecomemicuro
- **Servizi professionali**: ProntoPro, Cronoshare
- **Edilizia/casa**: Houzz, Edilportale

## Procedura verifica

1. Per ogni directory: cerca "[NomeAzienda] [Citta]"
2. Confronta NAP con riferimento dichiarato dal cliente
3. Annota divergenze (anche minori: "Via" vs "V.", "0212345678" vs "+39 02 12345678")
4. Genera link diretto per la correzione (form contatto/claim)

Tolleranza zero: anche divergenze ortografiche minime penalizzano l'algoritmo locale di Google.

# P03 — AI Legale e Contratti
## Servizio K2-AI
Analisi e redazione contratti, NDA, compliance legale, risk assessment, risposte a richieste legali standard.

## Skill Claude disponibili

| Skill | Descrizione |
|-------|-------------|
| `legal:review-contract` | Revisione contratti vs playbook di negoziazione: deviazioni, redline, analisi rischio |
| `legal:triage-nda` | Classifica NDA in GREEN/YELLOW/RED e identifica clausole critiche |
| `legal:compliance-check` | Verifica conformità di azioni, feature o iniziative alle normative applicabili |
| `legal:legal-response` | Genera risposte a richieste legali standard con template e escalation check |
| `legal:legal-risk-assessment` | Valuta e classifica rischi legali per severità e probabilità |
| `legal:vendor-check` | Verifica stato accordi con un vendor (MSA, DPA, SOW, scadenze) |
| `legal:brief` | Briefing contestuale per lavoro legale: research, incident response |
| `legal:signature-request` | Prepara e instrada documenti per firma elettronica |
| `diritto-italiano` | Consulente legale italiano: civile, penale, amministrativo, tributario, GDPR |
| `diritto-societario-italiano` | Diritto societario: SRL, SPA, SNC, fusioni, patti parasociali, M&A |
| `it-law-privacy-ai` | GDPR, AI Act, DMA, DSA, eIDAS, NIS2, firma elettronica |
| `antitrust-concorrenza-ue` | Art. 101/102 TFEU, merger control, AGCM, mercati digitali |

## Come usarle
Es: "analizza questo contratto di fornitura" → `legal:review-contract`
Es: "questo NDA ha clausole rischiose?" → `legal:triage-nda`

# P17 — AI Data & Analytics
## Servizio K2-AI
Agenti AI per analisi dati, SQL, visualizzazioni, dashboard interattive, machine learning e statistica applicata.

## Skill Claude disponibili

### Analisi e Esplorazione Dati
| Skill | Descrizione |
|-------|-------------|
| `data:analyze` | Analisi dati: da lookup rapido a report completo con trend e driver |
| `data:explore-data` | Profila dataset: shape, qualità, null rate, distribuzioni, anomalie |
| `data:validate-data` | QA analisi: metodologia, accuratezza, bias check pre-presentazione |
| `data:statistical-analysis` | Statistiche descrittive, test ipotesi, outlier detection, correlazioni |

### SQL e Query
| Skill | Descrizione |
|-------|-------------|
| `data:sql-queries` | SQL ottimizzato per Snowflake, BigQuery, Databricks, PostgreSQL |
| `data:write-query` | Traduce linguaggio naturale in SQL con CTE, window function, aggregazioni |

### Visualizzazione e Dashboard
| Skill | Descrizione |
|-------|-------------|
| `data:create-viz` | Visualizzazioni Python publication-quality (matplotlib, seaborn, plotly) |
| `data:data-visualization` | Chart design con principi accessibilità, colore e tipo grafico corretto |
| `data:build-dashboard` | Dashboard HTML interattiva con KPI card, filtri, tabelle, grafici |

### Machine Learning e Statistica Avanzata
| Skill | Descrizione |
|-------|-------------|
| `anthropic-skills:machine-learning` | ML teoria e pratica: regressione, classificazione, ensemble, reti neurali, CNN |
| `anthropic-skills:statistica-applicata-bocconi` | Inferenza statistica, test parametrici, ANOVA, OLS, regressione, diagnostica |

### Contesto Aziendale
| Skill | Descrizione |
|-------|-------------|
| `data:data-context-extractor` | Genera skill contestuale per data warehouse aziendale (schema, metriche, KPI) |

## Come usarle
Es: "analizza le vendite per regione degli ultimi 3 mesi" → `data:analyze`
Es: "scrivi la query per estrarre i clienti inattivi da 6 mesi" → `data:sql-queries`
Es: "crea una dashboard interattiva con i KPI commerciali" → `data:build-dashboard`
